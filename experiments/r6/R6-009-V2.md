## The six findings and their repairs

Findings 1, 3, 4 and 6 are repaired in locked code under the new lock; each
has its own named control in [`test_cohort.py`](test_cohort.py). Findings 2
and 5 are repaired in the non-locked auditor; each of the review's fifteen
probes is now a named control that rejects at the intended case.

1. **A D1 request could consume a C8 slot (P1).** `cohort_budget.reserve`
   now derives the funded task's manifest and challenge digests from the
   frozen task directory (`task_identity`) and `pricing_gate_v3.check_task_join`
   requires the request's own `binding.task_id`, `manifest_sha256` and
   `challenge_sha256` to be that task's before any reservation; the permit
   row carries `task_manifest_sha256` and `challenge_sha256`, and the actor
   repeats the join against its CLI task and the permit before the
   credential is read. Control `request_task_joined_to_funded_slot`: both
   crossings (D1 request funded as C8, C8 request funded as D1) are refused
   at the host with `cohort_request_task_mismatch` and no row is written; the
   actor refuses the same crossing with zero connections; the identity-only
   mismatch (right task name, wrong manifest) is `cohort_request_task_identity`.
2. **The auditor had lost the R6-008 case population (P1).** Rewritten below.
3. **Request schema pinned but unenforced (P2).** `pricing_gate_v3.check_request_grammar`
   enforces the frozen schema without a schema library — exact key sets,
   required bindings, task and digest forms, row and term shape, the
   integer-string grammar, nonempty rows, distinct row names — inside
   `check_envelope`, so both the host reservation and the actor run it.
   Control `request_grammar_enforced_at_admission`: eleven host mutations
   (the review's policy-digest injection and deleted `binding.task_id` among
   them) each refused with its own `contract_request_*` code, parity against
   the frozen schema for every mutation the schema expresses, and two actor
   cases with zero connections.
4. **Python equality admitted different option bytes (P2).** `same_json`
   requires type-exact JSON identity; `check_envelope` also requires the
   canonical bytes of the arguments to equal the canonical rendering
   (`contract_envelope_bytes`); `check_policy` uses the same rule for the
   policy's generation options and limits. Control
   `generation_option_types_exact`: `4096.0` for `4096`, `0` for `false`, and
   the same substitutions in a policy, each rejected separately.
5. **The auditor could succeed with a missing case (P2).** The expected case
   population is now derived from the frozen run population and declared
   outcomes; the audit is refused (`cases:population`) unless exactly that set
   was evaluated, and the controls runner refuses its record unless exactly
   its 29 named controls ran. The grant-ordering control now drives the
   production auditor over a coherently rebound transport record (see below).
6. **New slot parent directories were not made durable (P2).**
   `cohort_ledger.reserve` fsyncs every newly created path component,
   deepest first and each parent after its child, before the row is appended.
   Control `slot_hierarchy_durable` observes the actual `fsync` calls for a
   first task/first draw and for a new draw under an existing task.

Reporting corrections carried into this report: the v1 ledger had ten rows
