## 1. The export stdout is not required (finding 1)

[`deterministic_audit.py`](reviews/2026-09-23/deterministic_audit.py), revision 3. The export stdout is ignored by version control, so a
clean checkout lacks it. The solution join now rests on the retained bindings:
- the decompressed solution's digest equals the verdict's and the sealed export stdout digest;
- its size equals the export's recorded output and receipt;
- it names the site's local and whole declarations.

The stdout bytes are compared only when the file is present. The result reports how often that happened (`export_stdout_compared`).

## 2. The scan boundary (finding 2)

[`cohort_v9_audit.py`](reviews/2026-09-23/cohort_v9_audit.py), revision 2 of the file. An inventory path must take the scanner's own
form before any byte is read:
- relative and normalized, with no `.`, `..` or empty component;
- naming a regular file inside the declared root;
- reached through no symlink, since the scanner reports symlinks as irregular and never follows them.

Controls ([R6-014-V4-AUDIT-CONTROLS.json](reviews/2026-09-23/R6-014-V4-AUDIT-CONTROLS.json)). Each adds a clean entry with an authentic
digest and size for an outside sentinel:
- by its absolute path;
- by `../`;
- through a symlink inside the root.

Each is rejected at `operator_scan:report_bound` with **zero reads** of the sentinel, recorded by a read hook. A non-normalized spelling
of an inside file is rejected too.

The hook is shown to work in
[R6-014-V4-ESCAPE-HOOK-PRECONDITION.json](reviews/2026-09-23/R6-014-V4-ESCAPE-HOOK-PRECONDITION.json)
([`escape_hook_precondition.py`](reviews/2026-09-23/escape_hook_precondition.py)): the auditor as committed at `ac546085` accepts
each escape and reads the sentinel once.
