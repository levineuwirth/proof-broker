# Source provenance

`Pristine.lean` and the `upstream-*` configuration files were copied from
James Petrie's [VerInf](https://github.com/JamesPetrie/VerInf) commit
`c07e03c94884e9084ffaf7a7294fc0907672f6c2`, under `lean/BracketSpike/`.
The pristine Lean source also byte-matches the Proof Broker downstream demo's
`reference/Bracket.original.lean` at demo commit
`f208e978e2b2147cbd2d3844560ccbf140fbb690`.

The downstream demo's `LICENSE` identifies this derived source as MIT-licensed,
copyright (c) 2026 James Petrie. Its license notice is retained in
`downstream-LICENSE`. The historical VerInf commit itself has no root `LICENSE`
file; this attribution records the downstream notice rather than inventing an
upstream license file at that commit.

Generated challenge and episode artifacts preserve the original declaration
names. The permitted extraction changes are documented in `permitted.patch`.
